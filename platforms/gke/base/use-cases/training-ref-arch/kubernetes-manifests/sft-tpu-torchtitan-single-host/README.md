# Single-host TorchTitan TPU SFT Kubernetes Manifests

Kustomize base and overlays for single-host Supervised Fine-Tuning (SFT) on
Cloud TPU v6e (`tpu-v6e-2x2`, 4 chips on 1 `ct6e-standard-4t` node) using
PyTorch `torch_tpu` and TorchTitan.

See the step-by-step guide in
[Single-host Supervised Fine-Tuning (SFT) with TPUs on GKE using TorchTitan](/docs/platforms/gke/base/use-cases/training-ref-arch/sft-tpu-torchtitan-single-host/README.md).
